NEW PLAYBOOK STRUCTURE
═══════════════════════════════════════════════════════════════════════

1. LAB SETUP PLAYBOOK (RECOMMENDED - FASTEST)
   ├─ File: ansible/lab_setup.yml
   ├─ Role: lab_setup (split task files)
   ├─ Tasks:
   │  ├─ Configure hostnames (all devices)
   │  ├─ Setup OSPF routing (routers)
   │  ├─ Configure VLANs (switches)
   │  ├─ Setup DNS & NAT gateway (all devices)
   │  └─ Backup configurations
   ├─ Runtime: ~1-2 minutes
   └─ Perfect for: Initial lab setup

2. OPERATIONS PLAYBOOK (POST-LAB WITH TAG SELECTION)
   ├─ File: ansible/operations.yml
   ├─ Role: post_lab_operations
   ├─ Tasks (selectable with tags):
   │  ├─ validation (tag: validation)
   │  ├─ telemetry (tag: telemetry)
   │  ├─ health (tag: health)
   │  └─ security (tag: security)
   ├─ Runtime: ~2-3 minutes (all) or ~1 min per tag
   └─ Perfect for: Post-deployment validation & ongoing operations

3. PROVISION DEVICES PLAYBOOK (API-BASED)
   ├─ File: ansible/provision_devices.yml
   ├─ Inventory: ansible/inventories/inventory_provision.yml
   └─ Perfect for: Creating new device entries before lab setup
